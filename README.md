# Héliarque

Jeu de stratégie spatiale par navigateur, pensé d'abord pour le téléphone.

Votre station dérive autour de Vesper, une géante rouge qui s'éteint. Améliorez vos modules, lancez des recherches, construisez une flotte, explorez le secteur de la Faille et repoussez les corsaires, puis bâtissez l'Allumeur stellaire pour rallumer l'étoile.

Jouer : https://tom9603.github.io/heliarque/

Tout tient dans `index.html`. La partie est enregistrée dans le navigateur de l'appareil utilisé.
